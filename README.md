Hello there! Welcome to my Github profile.

Now you are probably asking where to start as there are so many beautiful projects.

Well, if I were you, I'd go for the [Javascript calculator](https://github.com/rixicz/calculator). It is not an artistic piece but the logic is bulletproof.
Same for [etch-a-sketch](https://github.com/rixicz/etch-a-sketch). 

However, if you are more intrigued about how to construct a whole new computer out of logic gates, have a look at the [Nand2Tetris](https://github.com/rixicz/Nand2Tetris) repo.
You can find loads of logic gates, hack assembly programs and vm programs there!

And lastly, I welcome you to see the [MicrosoftTechLearn](https://github.com/rixicz/MicrosoftTechLearn) repository. It documents my learning journey in various Microsoft technologies.

On the other hand, you don't have to limit yourselves only to those repositiories. Just go around and see for yourself!
